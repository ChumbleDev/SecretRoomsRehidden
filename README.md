# Secret Rooms Continuation
This mod has the goal of continuing Secret Rooms past 1.19. 
<br>It was forked directly from the unfinished and abandoned 1.20 branch from the orignal mod.

There are currently many issues preventing this fork from being ready-to-publish
<ul>
<li>Switch Probe crashes upon use</li>
<li>None of the blocks actually maintain their appearance upon reloading the world.
<br>They either default to stone or become completely unrendered and invisible.</li> 
<li>Secret Trapdoors' redstone signal activates one block above where it should.</li>
<li>The goggles only update the outline for secret room blocks when one is placed or destroyed</li>
<li>Probably a lot more issues. This is clearly not yet in a publishable state.</li>
</ul>
